# ReAct

- Цель: Найти один существующий сценарий `tests_integration.md`, который можно сделать более полным и проверяемым за счёт последовательного исследования связанных артефактов Практики 1, и локально усилить его Evidence подтверждённым фактом, не меняя поведение.
- Доступные входы: `tests_integration.md`, `adr.md`, `analysis.md`, `project_management.md`, `tests_unit.md`, `tests_e2e.md`.
- Разрешённые действия: (1) открыть текущий `tests_integration.md`; (2) открыть один связанный файл; (3) найти конкретный факт о взаимодействии компонентов; (4) сравнить факт с существующими integration-сценариями; (5) предложить одно локальное изменение существующего сценария; (6) перейти к следующему шагу только если предыдущего evidence недостаточно.
- Запрещённые действия: изменять файлы; запускать shell-команды и тесты; читать файлы вне разрешённого списка; добавлять новые требования; придумывать компоненты/взаимодействия; использовать другие техники Практики 2 как отдельный механизм.
- Максимальное число шагов: 6.
- Условие остановки: найден один существующий integration-сценарий, улучшаемый на основании подтверждённого взаимодействия компонентов; либо после 6 шагов недостаточно evidence для безопасного изменения. Если для следующего действия нужен файл вне списка — остановиться и спросить человека.

## Запрос

Какой из существующих сценариев `tests_integration.md` содержит evidence-колонку, менее привязанную к конкретному подтверждённому факту о взаимодействии компонентов, и как её локально усилить? Провести последовательное исследование: открыть `tests_integration.md` → для каждого потенциально уточняемого сценария сверить evidence с `analysis.md`, `adr.md`, `project_management.md`, `tests_unit.md`, `tests_e2e.md`; остановиться на первом сценарии, где evidence можно подтвердить источником и уточнить без изменения поведения, результата и формата строки.
