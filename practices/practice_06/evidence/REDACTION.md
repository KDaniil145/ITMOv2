# Обезличивание доказательств

Опубликованные HTTP-доказательства являются обезличенными копиями оригинальных результатов учебного эксперимента.

Временные токены сессий заменены на постоянные текстовые обозначения, а значения учебных паролей в HTTP-журналах скрыты.

Обезличивание не изменило количество HTTP-проверок, их статусы и результаты: 17 проверок Before и 39 проверок After.

Файл after/http-reaudit-689ad8w9/before-sha256.json хранит исторические контрольные суммы исходных, необезличенных доказательств. Эти суммы не предназначены для проверки опубликованных копий изменённых файлов.

Файл after/http-reaudit-689ad8w9/public-before-sha256.json содержит SHA-256 опубликованных файлов Before.

Оригинальные доказательства сохранены отдельно и не изменялись при подготовке публикации.
