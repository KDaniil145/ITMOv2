# ParcelBot — правила проекта для агентов

Требования и описание проекта: README.md

Код: service.py

Тесты: test_service.py

Проверка:
make test

Правила:
- исходный код ParcelBot изменяй только внутри этой директории demo
- конфигурационные файлы вне demo изменяй только после явного согласия пользователя
- не меняй публичное поведение существующих сценариев без прямого поручения
- не добавляй внешние зависимости без необходимости
- перед завершением запусти `make test`
- сначала покажи падающий тест для новой фичи, затем реализацию
- не делай commit без проверки пользователя

Текущее поведение choose_belt(weight, priority=False):
- weight <= 0 -> ValueError (независимо от priority)
- 0 < weight <= 10 ->
  - при priority=True возвращает "express"
  - при priority=False возвращает "standard"
- weight > 10 -> "heavy" (независимо от priority)
