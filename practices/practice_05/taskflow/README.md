# TaskFlow
Персональный планировщик для учебного курса AI-технологий. Сейчас доступны визуальная основа Dashboard, светлая и тёмная темы и проверка API. Kanban, задачи и SQLite оставлены для отдельного SDD в домашке №5 — см. docs/foundation.md.

## Окружение и установка
Node.js 24, npm 11, Python 3.12+ (подготовка выполнена с Python 3.14).

```bash
cd frontend
npm ci
cd ../backend
python3 -m venv .venv
.venv/bin/pip install -e '.[test]'
```

## Запуск в двух терминалах
Из frontend:
```bash
npm run dev
```
Из backend:
```bash
.venv/bin/uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
Открыть адрес Vite (обычно http://localhost:5173). Vite направляет /api на http://127.0.0.1:8000. Проверка: GET /api/health возвращает {"status":"ok"}. Без backend интерфейс остаётся доступным; индикатор отражает результат проверки при загрузке. После запуска backend обновите страницу.

## Проверки
Из frontend: `npm run lint`, `npm run typecheck`, `npm run build`.
Из backend: `.venv/bin/python -m pytest`.

Вручную: проверить обе темы на экранах 390 и 1440 px, сохранение выбора после перезагрузки, видимый клавиатурный фокус, переключение без localStorage, отсутствие вспышки другой темы и понятное состояние при остановленном API. Production-сборка frontend требует отдельной маршрутизации /api на backend при будущем размещении; встроенный proxy действует только в dev.

Цвета задаются семантическими CSS-переменными. Новые компоненты обязаны поддерживать обе темы. Облачных сервисов, авторизации и базы данных в основе нет.
