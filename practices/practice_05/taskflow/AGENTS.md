# Правила TaskFlow
- Kanban, задачи, CRUD, SQLite и формы реализуются только в отдельном цикле SDD домашки №5 после согласования UI и API-контракта.
- Все компоненты поддерживают обе темы через семантические переменные в frontend/src/styles/index.css. Не задавайте отдельные цвета в компонентах.
- Интерфейс и документация на русском. Код на английском.
- Новые зависимости требуют объяснения необходимости. Не добавлять авторизацию, Docker и облако без задачи.
- Проверки: frontend — npm run lint, npm run typecheck, npm run build; backend — python -m pytest.
